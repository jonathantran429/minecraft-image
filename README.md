# Minecraft Image

An experimental tool for turning images into Minecraft builds 
that use foreground blocks for thin details from one fixed viewpoint.

# Current Status

I'm working on representing blocks in a sparse 3D scene. Todos include
rendering, image comparison, search, and export.

# Development Setup

Create and activate a virtual environment, then run:
`python -m pip install -e ".[dev]"`

## Tests

Run `python -m pytest`.
